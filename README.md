# To-Do List (Desktop App)

A to-do list desktop app built with Python and Tkinter. Tasks have
priorities and due dates, and everything is saved automatically.

![Screenshot](screenshot.png)

## Features

- Add tasks with a priority (High, Medium, Low) and an optional due date
- Color-coded tasks, with overdue tasks highlighted
- Edit, complete, undo, and delete tasks
- Live search as you type
- Progress counter showing completed and overdue tasks
- Tasks are saved automatically to tasks.json

## How to run it

1. Install Python from python.org
2. Download todo_gui.py
3. Open a terminal in the same folder and run: python todo_gui.py
   (or python3 todo_gui.py on Mac)

Tkinter comes with Python, so there is nothing else to install.

## What I learned

Building a graphical interface with Tkinter, using classes, handling
button clicks and events, working with dates, and saving data to JSON.
